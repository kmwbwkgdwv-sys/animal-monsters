# アニマルモンスター（アニモン）

異世界の動物「アニモン」と旅をする、上から見下ろす3Dのアドベンチャーゲームです。
ブラウザで動き、**スマホ（横画面）とPCの両方で遊べます**。サーバー側の機能（データ連携・フレンド・トレード・対戦・ランキング）には **Firebase（Realtime Database）** を使います。

---

## 1. すぐに遊ぶ（ローカル）

ES Modules を使っているため、`index.html` をダブルクリックではなく **Webサーバー経由**で開いてください。

```bash
# どちらか1つ
npx serve .
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。オンライン機能以外はすべて Firebase なしで動きます。

## 2. Firebase の設定（データ連携・フレンド・トレード・対戦・ランキング用）

プロジェクト **animal-monsters** の設定は `js/firebase-config.js` に入力済みです（Realtime Database：`https://animal-monsters-default-rtdb.asia-southeast1.firebasedatabase.app`）。
残りはコンソールでの3つの作業だけです。

1. **Authentication → ログイン方法 → 「匿名」** を有効にする。
2. **Realtime Database → 「ルール」タブ** を開き、中身をすべて消して **`database.rules.json` の内容** を貼り付け、「公開」を押す。
3. ゲームを公開する（どちらか）
   - Firebase Hosting：`npm install -g firebase-tools` → `firebase login` → `firebase deploy`（サイトとデータベースのルールをまとめて公開。`.firebaserc` は animal-monsters に設定済み）
   - ほかのサーバーで公開する場合は **Authentication → 設定 → 承認済みドメイン** にそのドメインを追加。

> Web 用の API キーはブラウザに配信される前提の値で、データの保護は `database.rules.json`（同梱）のルールで行います。
> 念のため Google Cloud コンソールで API キーに「HTTPリファラー制限」をかけておくと安心です。

### Realtime Database のデータ構成

| 場所 | 内容 |
|---|---|
| `players/{pid}` | プレイヤー（持ち主のuid・名前・フレンドコード） |
| `friends/{pid}` `requests/{pid}` `invites/{pid}` | フレンド・届いた申請・届いた招待 |
| `codes/{フレンドコード}` | フレンドコード → pid |
| `rooms/{id}` | 対戦・トレードのルーム（行動・チーム・交換データをリアルタイム同期） |
| `saves/{pid}` | クラウドセーブ（連携したすべての端末で共有・自動同期） |
| `transfers/{連携コード}` | 連携コード → pid（コードを知っている端末だけが連携できる） |
| `rankings/{pid}` | ランキング用の公開成績（名前・図鑑登録数・色違い数・個体値MAX数・パーティー）。書き込みは本人だけ |
| `worlds/{ホストpid}` | いっしょのワールド（`meta`＝開いているか、`members/{pid}`＝位置・見た目・先頭のアニモン）。書き込めるのは本人と、ホストのフレンドだけ |
| `gifts/{pid}/{id}` | 運営からの プレゼント（お金・アニモン・メッセージ）。管理者だけが 書き、本人の ゲームが 受け取って 消す |
| `giftsAll/{id}` | 運営から **全員への** プレゼント（`until`＝期限、`newOk`＝あとから 始めた 人も OK）。1アカウント 1回だけ（受け取った 記録は セーブの `giftsGot`）。管理者だけが 書ける |
| `announcements/{キー}` | **お知らせ**（`title`・`body`・`date`・`at`・`hidden`）。だれでも読めて、書けるのは `admins` に登録した管理者だけ（管理サイト `/admin/`） |
| `admins/{UID}` | 管理者（値は `true`）。コンソールからだけ登録できる |

対戦は **同じ乱数シード＋同じ入力なら同じ結果になるバトルエンジン** を使い、お互いの行動だけを送り合う方式です。

## 4. ゲームの内容（ご要望との対応）

- **タイトル画面**：アニマルモンスター／最初から始める／続きから始める／データ連携（スマホ・パソコン共通）・引き継ぎ／設定
- **音楽**：BGMはその場で生成。iPhone/iPad（Safari 16.4以降）では `audioSession = "ambient"` に設定し、**他のアプリで流している音楽を止めません**。設定で BGM・効果音を個別に ON/OFF、OFF のときは音声機能そのものを起動しません。
- **軽量モード**：画質・描画距離・草の量を下げて軽くします。
- **主人公**：肌・髪型・髪色・服・下（ズボン/短パン/スカート）・くつ・ぼうしをカスタム。手足が動くアニメーション。
- **大陸**：1つの大陸に平原・森・湖・砂漠・渓谷・氷山・湿原・高原・火山・聖域（中心）の10地域＋海。町10か所、地域ごとに野生のアニモンのレベル帯があります。
- **アニモン 200種**（御三家9・伝説2・その他189）。全種に名前・見た目（進化後も別モデル）・タイプ・種族値・特殊能力・8つの技・図鑑説明・生息地。
  - 最初の相棒：炎のセリック／水のシドー／草のモーラ（各2回進化）
  - 伝説：エンテイオウ（炎・ドラゴン／耐久・攻撃が高く遅い）とナルメクシア（水・飛行／攻撃・素早さが高く耐久やや低め）。ストーリーで**どちらか1匹だけ**仲間になり、色違いなし。**個体値は4つとも10〜15のランダム**で、受け取った瞬間に決まって保存されます（読み込み直しても変わりません）。
  - 特別技：伝説に1つずつ＋一部の通常アニモンにも（名前・性能はすべて別）。
- **能力と個体値**：アニモンは種族ごとに HP・攻撃・防御・素早さ（種族値）が決まっていて、個体値（1〜15の抽選）で少しだけ上下します。**7.5 が基準**で、15 なら種族値 **+9%**、1 なら **−7.8%**（1 ごとに 1.2%）。平均的な個体はこれまでとほぼ同じ強さで、インフレしません。アニモンを押すと「種族値 → 個体値 → 調整後の値 → いまのレベルの能力」を一覧で表示します。
- **出現率**：種類ごとに出やすさが違い、**強い（種族値の合計が高い）アニモンほど出にくく**なります。図鑑に「出現しやすさ ★〜★★★★（よく見る／ふつう／少ない／めずらしい）」を表示。めずらしいアニモンはミニマップで紫の点、出会うと「めずらしい アニモンだ！」と表示されます。
- **色違い**：1/1000。フィールドで近くに現れたとき・バトル（野生・トレーナー・フレンド対戦）で出てきたときに **「キラーン！」**（光の十字・効果音・星のはじけ）。歩いている間もキラキラ光り、ボックスでは右上に ✨。
- **18タイプ**と相性（ポケモンと同じ）。素早さが高いほど先に行動し、相手の攻撃を避けやすい。
- **バトル**：ターン制（たたかう／つかまえる／てもち／にげる）。強い相手ほど逃げにくい。技には使用回数（PP）。
- **捕まえ方**：エサをあげて懐かせる。HPが低いほど・良いエサほど懐きやすく、自分よりずっとレベルが高い相手はほぼ無理。
- **エサは4種類**：ふつうのエサ★（×1.0・最初から）→ おいしいエサ★★（×1.6・紋章1個）→ ごちそうエサ★★★（×2.4・紋章3個）→ きわみのエサ★★★★（×3.5・紋章6個）。ストーリーが進んで紋章を手に入れると、ショップに順に入荷します（入荷時にお知らせ、ショップでは NEW 表示。まだ入荷していないものは「紋章○個で入荷」と表示）。
- **ダブルバトル（2対2）**：素早い順に、同じチームが連続しないよう交互に行動。「プラス／マイナス」「ともだちパワー」「なかまおもい」「おとりのさけび」「エール」など組み合わせで強くなる要素があります。
- **持ち物 61種**（いのちのお守り、呪いのお守り（進化しない）、タイプ強化×18、タイプよけ×18 など）＋回復アイテム（少し／ほどほど／全回復・復活・技回復）＋「おもいだしの巻物」。
- **パーティー6匹**（同じアニモンは不可）、**経験値は6匹全員**に入る。レベル上限99、上がりにくめ。クリア後は経験値+100%。
- **病院**（回復・技の回復・買い物・パーティー変更）と**ショップ**。
- **草むら**・**歩いている野生アニモン**に触れる・**水上**でエンカウント。地域ごとに出るアニモンが異なり、その場所にしかいない種も。
- **ライド**：陸を走る・海を泳ぐ・空を飛ぶ（一部のアニモン）。
- **ファストトラベル**：大陸各地の光る岩にさわって登録。岩にさわると **大陸マップが開き、光っている岩（💎・病院のある町は 🏥）を押すと「ワープ！」の吹き出し** が出て、そのままワープできます（横の一覧から選んでもOK。病院の前にも岩があります）。
- **マップ**、**図鑑**（初めて捕まえると登録画面、未入手は生息地と入手方法のみ／一部は ？？？）、**ボックスの絞り込み**（名前・タイプ・個体値・色違い・お気に入り・並び替え）、**ニックネーム**。
- **ストーリー**：全11章。地域を少しずつ解放し、最後は最もレベルの高い「聖域の奥地」と「深淵の迷宮」を解放。途中で仲間になるアニモン（ルミナのルル）、ムービー（カットシーン）、スキップ機能、左上に目的を表示。
- **サイドストーリー 10本**（クリアしないと手に入らないアニモンあり）、**ダンジョン 6か所**（推奨レベル・限定アニモン・宝箱・主）。
- **フレンド**：フレンドコードで申請・承認。**トレード**（伝説のアニモンは交換不可。個体値・レベル・技・色違いはそのまま引き継ぎ、抽選しなおしません。交換する前から **相手のアニモンの個体値4つ・合計・ランク・能力・技・持ち物** が見え、「🔍 くわしく見る」で詳細も確認できます。OK のあとで相手がアニモンを変えると OK は自動で取り消されるので、見たものと違うアニモンが届くことはありません）、**対戦**（シングル/ダブル、3匹/6匹、レベルそのまま/99固定）。
- **いっしょのワールド**：フレンド画面の「🌏 いっしょに」でフレンドを自分のワールドに招待 → 相手が参加すると、**同じ大陸をおたがいの姿（先頭のアニモン・ライド中のアニモンも）を見ながら歩けます**。近づいて A（Space）で「あいさつ・対戦・トレード」。招待はゲーム中いつでも画面上部に届きます。ストーリーやアニモンはそれぞれのデータのまま。
- **ランキング**（メニュー →🏆）：図鑑登録数で順位（同じ数は同順位）。上位50人と自分の順位を表示し、**それぞれの人がストーリー何章まで進んでいるか（クリア済みは「クリア」）** も表示。名前を押すとその人の **パーティー編成・色違い獲得数・個体値MAX所持数・図鑑登録数・ストーリーの進み具合（章のゲージ）** などが見られます。セーブするたびに自動で更新されます。
- **データ連携（スマホ・パソコンで同じデータ）**：タイトル →「データ連携」で、1台目で連携コードを発行し、2台目で入力すると、両方の端末で同じセーブデータを遊べます（何台でもOK）。セーブは自動でクラウドにも保存され、「続きから始める」やアプリに戻ったときに新しいほうを読み込みます。両方で別々に進めた場合は、どちらを使うか選べます。
- **視点の操作**：フィールドでは画面をなぞる（PCはドラッグ／Q・E）と、主人公のまわりをぐるっと見渡せます。移動の方向は見ている向きに合わせて変わります。

## 📢 お知らせの出し方（管理者用）

ゲームを開いたとき（タイトル画面）に、**まだ見ていないお知らせを 1 回だけ** 表示します。2 回目からは出ず、タイトル画面右上・メニューの **「📢 お知らせ」** ボタンでいつでも全部見られます（未読の数のバッジ付き）。

お知らせは **専用の管理サイト `/admin/`**（例：`https://animal-monsters.web.app/admin/`）から送ります。スマホからでも使えます。

### 最初に 1 回だけする準備
1. **ルールを公開**：`database.rules.json` を Realtime Database の「ルール」タブに貼り付けて「公開」（または `firebase deploy`）。
2. **ログイン方法を有効に**：Firebase コンソール →「Authentication」→「ログイン方法」→ **「メール / パスワード」を有効** にする（「匿名」は今までどおり有効のまま）。
3. **管理者を作る**：「Authentication」→「ユーザー」→「ユーザーを追加」で、管理者のメールアドレスとパスワードを登録。
4. **サイトを公開**：`firebase deploy`（`admin/` フォルダもいっしょに公開されます）。
5. **管理者に登録**：`/admin/` を開いてログイン →「まだ管理者に登録されていません」と **UID** が出るのでコピー → コンソールの「Realtime Database」→「データ」で、ルートに `admins` を作り、その中に **名前＝UID・値＝true** を追加 → ページを再読み込み。

### 送り方
- タイトル（60 文字まで）・本文（3000 文字まで・改行もそのまま）・日付を入れて **「📢 送信する」**。プレビューでゲームの中の見た目を確認できます。
- 送ったものは下の一覧で **✏️ 直す／🙈 非表示にする（👁 表示する）／🔁 もう一度全員に表示／🗑 削除** ができます。
  - 「直す」では、もう見た人には再表示されません。もう一度見せたいときは「もう一度全員に表示」（新しいお知らせとして送りなおし、前のものは非表示）。
- 既読は端末ごとに記録します。

### ルール（お知らせ・管理者の部分）
```json
"admins": {
  "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": false }
},
"announcements": {
  ".read": true,
  ".indexOn": ["at"],
  "$id": {
    ".write": "auth != null && root.child('admins').child(auth.uid).val() === true",
    ".validate": "newData.child('title').isString() && newData.child('title').val().length <= 60 && newData.child('body').isString() && newData.child('body').val().length <= 3000"
  }
}
```
- お知らせは **だれでも読める**（ログイン前のタイトル画面でも読むため）。**書けるのは `admins` に登録した人だけ**。
- `admins` は **コンソールからしか書けない**（アプリやサイトからは だれも 管理者を 増やせない）。
- 管理サイトのログインは、ゲームのログイン（匿名）とは別に保存されるので、同じブラウザでゲームを遊んでも混ざりません。

（コンソールで直接書く場合は、`announcements` の下に、キー（例 `n001`）・`title`・`body`・`date` を追加します。新しいお知らせは必ず新しいキーで。）

## 🔧 ストーリーの途中から始まるアカウントを作る（テスト用）
管理サイト `/admin/` の下のほうの **「🔧 ストーリーの途中から始まるアカウントを作る」** で、**ストーリーを何章までクリアしたか（1〜11）** を選んでアカウントを作り、**引き継ぎコード** を表示します（管理者だけ・スマホからでも OK）。

| 選択 | 始まるところ |
|---|---|
| 第1章まで クリア | 第2章の はじめ（相棒だけ・はじまりの町） |
| 第4章まで クリア（初期値） | 第5章の はじめ（紋章2個・みなとまち） |
| 第8章まで クリア | 第9章の はじめ（紋章6個・ルルは さらわれ中・きりの集落） |
| 第10章まで クリア | 第11章の はじめ（紋章8個・ルルが 戻った あと・ほむらの里） |
| 第11章 クリア | ストーリー全クリア（伝説 Lv80・他の相棒2匹・金の王冠・聖域の奥地 解放） |

**中身の 調整**：「📝 中身を 調整する」で、所持金・**図鑑登録数**（捕まえた ことが ある 種類の 数）・**捕まえた数**（捕まえた アニモンの 匹数。同じ 種類を 何匹も 捕まえる ことも あるので 図鑑登録数 以上）を 決められます。足りない 種類は その章までに 出会える アニモンから、捕まえた 子は 図鑑登録した 種類から、**出やすい アニモンほど 多く** ランダムに 選んで ボックスに 入れます（レベルは 出会う 場所に 合わせる・持てる数まで）。手持ち・ボックスの アニモンも 変えられます。技は 名前だけでなく タイプ・威力・命中・PP・説明・追加効果まで カードで 見られます（覚えられる 技を 全部 見ることも できます）。また、手持ち・ボックスの アニモンを 変えられます。アニモンは 画像と 名前の 一覧から 選び（ダンジョンの主・伝説・サイドストーリー などの 札つき）、レベル・通常／色違い・個体値・ニックネーム・持ち物、望む 子だけ 技構成も 決められます。

**プレゼント**：「🎁 プレゼントを 送る」で「1人に 送る」「全員に 送る」を 選べます。全員の ときは 受け取れる 期限と「これから 始める 人も 受け取れる」を 決められ、1アカウント 1回だけ 受け取れます（「終わらせる」で 止められます）。1人の ときは 引き継ぎコード か フレンドコードで 相手を さがし、お金（足す／減らす）・道具（金の王冠・銀の王冠・ふしぎなアメ）・アニモン（同じ 編集画面）・メッセージを 送れます。相手が ゲームの フィールドに いるとき 自動で 届きます（セーブを 直接 書きかえないので データの 衝突が 起きません）。まだ 受け取られていない プレゼントは 取り消せます。

ストーリーのデータ（STEPS・SCENES）を順になぞって、紋章・解放した地域・倒したトレーナー・ルル・伝説・王冠をゲーム本編と同じ状態にそろえます。手持ちのレベルはその章の守護者・ライバルに合わせた目安です。章を選ぶと、その下に紋章の数・手持ちのレベル・スタート地点がすぐ表示されます。名前（初期値 `nekojita`）・最初の相棒・（第11章のときは）選んだ伝説を選んで作成 → ゲームのタイトル画面「🔑 引き継ぎコードの発行・アカウント引き継ぎ」→「コードを入力して連携する」に入力します。管理サイトを開いたブラウザのゲームのセーブは変わりません。

PC でローカルから作る場合は `tools/make-account.html` も使えます（`npx serve .` → `http://localhost:3000/tools/make-account.html`。公開サイトには含まれません）。

## 5. v1.4 の変更点

### 直したバグ
- **バトル・進化・ダンジョンクリアのあとに固まる／再起動するとバトル前に戻る**：バトルの結果（経験値・つかまえた子・勝ったトレーナー）を、会話や進化の演出より先にセーブするようにしました。演出の途中でエラーが出ても、画面と状態を必ず元に戻します。バトル画面・ダンジョンの 3D データを終わるたびに片付けて、くり返し遊んでもスマホのメモリがいっぱいにならないようにしました。さらに「会話もメニューも出ていないのに動けない」状態が続いたら自動で戻す見張りを入れました。
- **ダンジョンの主（や野生）に負けると何もない場所に飛ばされる**：ダンジョンから出てから病院に運ばれるようにしました。
- **負けて町に戻ったのに動けない**：ワープ先・復活した場所が建物や岩の中なら近くの歩ける場所へずらします。動こうとしても動けない場所に埋まったときも自動で外に出します。会話中は A ボタンでも会話を送れます。
- **技のダメージが表示と合わない**：HP の表示を「その場面の値」で出すようにしました（ターンの後のダメージ＝毒・反動などが先に減って見えていました）。ダメージ・回復の数字もアニモンの上に表示します。
- **キーボードで何もしていないのに右に進み続ける**：キーを離した合図を取りこぼしても歩き続けないようにしました（バトル開始・終了・画面の切り替え・フォーカスが外れたとき・⌘/Ctrl・日本語入力中など）。スマホのスティックも同様。
- **トレーナーのアニモンを捕まえられる**：トレーナーの子にしるしを付けて、エンジン側でも捕まえられないようにしました。野生のアニモンが町の中やトレーナー・住民のすぐそばに出たり近づいたりしないようにしました（トレーナーの連れているアニモンと間違えないように）。
- **ライドしているとキャラとアニモンが重なる・宙に浮く**：アニモンの形から背中の高さを計算して座らせます（2本足の子は肩車）。
- **ライドできるのに乗れない**：パーティーにいない（ボックスの）子や、ひんしの子にも乗れるようにしました。
- **バトルで「にげる」を 連打すると 確認の ボタンが たくさん 出て、戻ると 固まる（再起動で データが 戻る）**：選択肢は 同時に 1つだけ に し、連打しても 1回だけ 動くように しました。
- **パーティー画面で 長押し中に 閉じると、つかんだ 子が 画面に 残って 固まる**：閉じたら すぐ 片付けます。
- **スマホで 下の ボックスの 子を 長押ししても 上に 運べない**：指を 上下に 動かしても ドラッグが 続くように しました（画面の 端で 自動スクロール）。
- **一部の アニモンの 画像が 出ない**（ユキヒメリア・ペンキング・ガマオヤブン・オバケンゴウ・テンシエル・ヤミノオウ・サボトゲラ）：マントなどの 薄い 部品が 形に ならず、画像の 範囲計算が こわれていました。200種 すべて 表示されることを 確認しました。
- **サイドストーリーを 始めた とき「Cannot read properties of undefined (reading 'root')」の エラー**：ほかの サイドストーリー（空のたまご など）の 光る しるしが 出ている ときに、人の 配置を 作りなおす 処理が 止まっていました。
- **空を 飛んで いるのに 下の 木を 切ったり 岩を くだいたり できる**：飛んで いる あいだは 地面の もの（木・岩・しげみ・人・落とし物・入口・ふしぎなアメ）に さわれないように しました（おりてから）。
- **トレーナーから逃げると、すぐにまた目が合って勝負になる**：逃げた（勝たなかった）道ばたのトレーナーは、いちど 13m 以上 離れるまで 目が合っても 勝負を挑んでこないようにしました。話しかければ いつでも 再戦できます。

- **ニックネームをボックスから変更**：ボックスの「✏️ ニックネーム」で押した子の名前を変えられます（詳細画面の ✏️ でも）。ボックスに名前も表示。

## 6. v1.3 の新機能

- **タイトル画面**：PC・スマホとも、中央にロゴ → リボン → 4つのボタン（最初から／続きから／🔑 引き継ぎコードの発行・アカウント引き継ぎ／設定）。
- **ミニマップ**（右上）：見ている方向が上。町・岩・ダンジョン・野生のアニモン（色違いは黄・めずらしい子は紫）・トレーナー・おつかいの印。押すと大陸マップ。
- **次の行き先の案内**：左上の目的の下に「矢印・行き先・距離」、ミニマップに ⭐（遠いときは ふちに矢印）、フィールドに **光の柱**。
- **ストーリー一覧**：左上の目的の枠を押す（またはメニュー →📜）と、**メインストーリー（章・目的・目的地・距離）・サイドストーリー（進行中／未受注／クリア・目的・目的地）・おつかい** を一度に確認。「地図」ボタンでその場所を大陸マップに表示。
- **ストーリーの順番**：場所に着くと始まるストーリーのイベントは、始まる前に「進める／あとで」を確認します。「あとで」を選ぶと、すぐには始まらないので、前の章のやり残しを先に終わらせられます。あとで始めるときは、①その場所をいったん離れてもどる ②**光の柱（目的地）** に行く ③左上の目的を押して「📖 ここで イベントを 始める」 のどれでも OK。地域の境目をかすっただけでは始まりません。
- **目的地の光の柱**：町が目的地のときは、噴水の中ではなく **噴水の手前の広場**（光る岩とのあいだ）に立ちます。ほかの目的地も、建物や岩の中に重なるときは近くの歩ける場所にずらします。
- **大陸マップ**：ドラッグで移動・2本指／ホイールで拡大縮小、＋／－／📍現在地／⭐行き先／全体。スマホでも全体が見えます。
- **UI**：メニューをカード型に（パーティーの顔ぶれとHP・次の目的・各ボタンの件数）、HUD・会話の箱などを調整。
- **技の効果**：バトルで技を選ぶとき、威力・命中に加えて「10%で やけど」「自分の攻撃↑↑」「反動」などを表示。マウスを乗せる／長押しで、くわしい説明が出ます（アニモンの詳細・図鑑・技を覚えるときも表示）。
- **セーブした場所から再開**：セーブ（自動セーブ含む）すると今いる場所を記録し、アプリを閉じても「続きから」でその場所に出ます（ダンジョンの中なら入り口の前、水上・空中なら最後に立っていた陸地。立てない場所なら最後の病院の前）。
- **進化前・進化後の見た目**：見分けにくかった 41 系統の進化後を、まったく別の体型に作り直しました（獅子の騎士・巨大な亀・大角のヒツジ・カブト武者・コンドル・女王クラゲ・皇帝ペンギン・マンモスの王 など）。
- **ダンジョンの主は捕まえられる**：個体値は4つとも **6〜15**。捕まえやすさも少し上がっています。
- **ダンジョンは何度でも周回できる**：入るたびに迷路の形が変わり、主と宝箱が復活します。クリアするたびに主と野生のアニモンが少しずつ強くなり（最大 +10レベル）、周回のごほうび（少しのお金＋回復道具・レベルアメ・持ち物・巻物など。周回するほど良い物が出やすい）がもらえます。主は毎回なつかせられます。看板とストーリー一覧にクリア回数を表示。
- **おつかい（町の住民・通行人）**：各町に3人（町を歩く通行人を含む）。頭の上の 🧺 が お願い、💰 が報告できる、📦 が届け物の相手。内容は「木を切って木材を持ってくる」「岩をくだいて石ころ」「木の実・キノコ・サボテンの実・結晶のかけら・火山の鉱石」「○タイプの野生アニモンを追いはらう」「○タイプのアニモンを見せる」「ほかの町の人に荷物を届ける」。お礼は **100〜500円くらいのお小遣い**（インフレしないよう少なめ）。素材はフィールドの木・岩・しげみなどの前で A（Space）。メニュー →🧺 で一覧。
- **銀の王冠・金の王冠**（1アカウント1つずつ・使うと なくなる）：**銀の王冠**＝第6章クリア（4つ目の紋章）のごほうび。アニモン1匹の個体値を1つ選んで最大（15）に。**金の王冠**＝ストーリー全クリアのごほうび。アニモン1匹の個体値を4つとも最大に。バッグの「その他」から使えます（ボックスの子にも使えます）。すでに条件を満たしているセーブデータには、次に遊んだときに届きます。ストーリー一覧でも入手状況を確認できます。
- **アプリアイコン**：iPhone の「ホーム画面に追加」で、タイトル画面の景色（伝説の2匹・木々・光のすじ）に「アニマルモンスター」のロゴを重ねたアイコンになります。名前は「アニモン」。Android 用（まわりを丸く切られても大丈夫な版）も同梱（`icons/`）。
- **伝説の2匹を かっこよく**：エンテイオウは 胸を張った王の姿勢・長い首・大きく広げた炎色の翼・金の先の角と王冠のとげ・首すじの炎のたてがみ・金の鎧のうろこ。ナルメクシアは 1本につながったしなやかな体（うねっても切れ目ができない）・水晶の枝角・流れるたてがみ・すきとおる大きなひれの翼・リボンのような尾びれ・まわりを回る光の真珠。タイトル画面でも大きく映るようにしました。
- **パーティー編成を 指で スライド**：メニュー →🐾パーティー で、アニモンを **長押し（PCはそのままドラッグ）してほかのアニモンに重ねると入れかわります**。下に並ぶボックスへ落とすと預けて、ボックスの子を上のアニモンや「空き」に落とすとパーティーに入ります（同じアニモンは1匹まで・パーティーは最低1匹）。長押しせずになぞった場合はふつうにスクロール、タップは今までどおり詳細画面。
- **アニモンの所持上限**：パーティーとボックスを合わせて、はじめは **100匹**。紋章を1つ手に入れるごとに +75匹（紋章8つで700匹）、ストーリークリアで **800匹**。増えたときはお知らせが出ます。いっぱいのときはバトルで「つかまえる」を押すと「いっぱいで これ以上 なかまに できない」と出るので、逃がして空きを作ります（ストーリーやサイドストーリーでもらえるアニモンは、いっぱいでも受け取れます）。持てる数はメニューのボックスの欄・ボックス画面・パーティー画面に表示。
- **逃がす**：アニモンの詳細画面に「🌿 逃がす」（ボックスの子もパーティーの子も。パーティーは最低1匹残ります）。ボックス画面の **「🌿 まとめて逃がす」** で、押した子を選んで一度に逃がせます（「表示中を 全部 選ぶ」で、名前・タイプ・個体値などで絞り込んだ子をまとめて選択）。色違い・個体値の高い子・お気に入りが入っているときは確認で知らせ、10匹以上は2回確認します。持たせていた道具はバッグに戻ります。ルルと伝説のアニモンは逃がせません。
- **操作の感度（設定 →「🎮 操作の感度」）**：スライダーで調整（ふつう＝1.0倍）。**視点を回す速さ（左右）・（上下）** 0.3〜2.5倍（指でなぞる／PCのドラッグ・Q/E キー）、**左右反転・上下反転**、**スティックの感度** 0.5〜2倍（スマホのみ。高いほど少したおすだけで速く走ります）、**ズームの速さ** 0.3〜2.5倍（2本指／マウスホイール）。「ふつうに もどす」で全部もとに戻ります。タイトル画面の設定・ゲーム中のメニューの設定のどちらからでも変更でき、すぐ反映・端末に保存されます。
- **会話の重複をなくしました**：研究所の入口と博士、家の入口とママが同じ話をしていたので、博士・ママに話しかけるだけにしました（ママは話すと休ませてくれます）。
- **右上のボタン**：マップ・メニュー・ミニマップ・視点リセットの押せる範囲を見た目より少し広げ、押した指が少しずれて離れても反応するようにしました（左上の目的の枠も同じ）。
- **スマホの画面**：横にしたときに下が黒くなる問題を修正（描画サイズを何度か合わせなおし、ずれていたら自動で直す）。3D表示が壊れて真っ黒になったときは、自動でセーブして読み込みなおし、続きから再開します。暗転が残ってしまったときも自動で戻します。

## 7. 見た目・スマホ対応・新機能（v1.1〜v1.2 の変更点）

- **アニメ調の描画**：トゥーン（セル）シェーディング＋輪郭線、太陽の影（リアルタイムの影）、風で草がなびく地面、空・雲・遠くの山並み。
- **アニモン**：なめらかな体（SDFスカルプト）に、アニメ風の瞳・口を表面に貼り付け。伝説の2匹は専用モデル。ムービー・バトル・図鑑・ボックスすべて同じモデルです。オープニングの語りには伝説の2匹とルミナの挿し絵が出ます。
  - **198種それぞれに「姿の設計」**（`js/data/designs.js`）：ネコ・キツネ・オオカミ・ネズミ・ウサギ・クマ・ヒツジ・ウマ・シカ・ヤギ・サイ・マンモス・ラクダ・ワニ・トカゲ・モグラ・アルマジロ・ビーバー・カワウソ、格闘家・騎士・お姫さま・天使・カエル・ペンギン、ひよこ・猛禽・フクロウ・アヒル・白鳥・コウモリ・不死鳥、金魚・イルカ・サメ・クジラ・アザラシ、ヘビ・コブラ・東洋の竜、チョウ・ハチ・カブトムシ・クモ・カニ・サソリ・トンボ、スライム・おばけ・星・クラゲ・宝石・ちょうちん、サボテン・花・わた毛、岩・ゴーレム・石像 など約110種類の骨格から作ります。
  - 進化前は頭が大きく脚が短い「ちびっこ体型」、進化するほど頭身が上がり、体型そのものが変わる系統も多数（ひよこ→小鳥→猛禽、子グマ→格闘家→巨大な獣、子ウマ→ウマ など）。
  - 目（キラキラ・つぶら・まんまる・ねむそう・つり目・怒り顔・光る目・複眼）と口（ω・笑顔・キバ・歯・一文字）、模様（しま・ぶち・背中の濃い色・くつ下・しっぽ先）で、かわいい子といかつい子をはっきり分けています。
  - **大きさも種ごとに違います**（手のひらサイズ〜人より大きい）。フィールドの野生アニモンも本来の大きさで出現し、大きい子は開けた場所にだけ現れ、のっしのっしと歩きます。バトルでは差を残したまま見やすい大きさに調整します。
- **主人公・町の人**：3頭身のアニメ調キャラクター（髪型6種・帽子・スカート等も反映）。遠くの人は近づいたときに順番に組み立てるので、町に入っても止まりません。
- **大陸**：起伏の大きい丘・台地・段々の高原、木や岩・花・草むらの密度を上げ、地面にも影と風のうねりを付けました。
- **タイトル画面**：伝説の2匹・御三家・歩くアニモンが動く背景、光の筋、ロゴ（立体文字）とメニュー。フォントは見出し「Dela Gothic One」、本文「M PLUS Rounded 1c」。
- **バトル**：画面の切り替え演出（ワイプ）、技名のカットイン、着地の土ぼこり・ヒットストップなど。横長のスマホでは下の欄に隠れないようカメラを調整。
- **スマホの不具合修正**
  - 画面を連打しても拡大されないようにしました（ダブルタップ拡大を無効化。2本指ズームはフィールドだけ）。
  - 図鑑登録の画面：「完了」ボタンが必ず画面内に表示され、**画面のどこをタップしても閉じます**。
  - 横画面で下が見切れる問題：横向きでは文字・ボタンを小さくし、収まらない画面は**上下にスライド（スクロール）**できるようにしました。
  - 横画面で絵が引き伸ばされて見える問題：3Dの描画サイズを実際の表示サイズに合わせ、横に広い画面では画角を広げすぎないようにしました（端のゆがみが出ません）。
  - 名前などの入力欄をタップしたときに iPhone が画面を拡大してしまう問題も防いでいます（入力欄の文字を16px以上に）。
- 古いスマホで重いときは **設定 →「軽量モード」** をONにしてください（影・アンチエイリアスを切り、モデルを軽くします）。
